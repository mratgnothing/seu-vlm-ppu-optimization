## 3. 关键问答

**为什么题目讲量化，你们正式结果是 BF16？**

我们分别检查了允许的权重变换、关键形状、kernel 和运行时依赖。当前正式证据最充分的是 BF16 融合与提交优化。PPU 全模型量化没有形成完整性能/精度闭环，不能把微基准或手机公开量化包代替它。若独立量化结果是最终硬性要求，这项需要优先补验。

**2.7 倍怎么测，为什么不是全量？**

2026-09-01 四个独立进程按 ABBA 顺序运行同一 CN20、每进程预热两条，每臂两次。两次平均吞吐的中位数分别是 49.2195 和 133.623。全量数据主要支持后期各增量的精度与配对性能门禁，不能把它合并成最终总栈的全量加速结论。

**准确率一致是否证明没有数值变化？**

不能。CN20 总栈答案和正确性一致，但 token 数只有 15/20 一致，且没有严格全文对照。某些后期增量有独立 full-text exact 证据，它只适用于该候选相对其前一基线。

**为什么不选更快的 single-GEMV？**

双语完整集回归中英文少答对一题，正式策略要求保守，因此降级实验分支。b/a 仅合并小投影，双语全文与答案门禁通过。

**为什么 TTFT 只改善几个百分点？**

大部分优化针对每个 token 重复发生的 decode 开销。首 token 还包含输入和视觉路径，prefill 的工作不同，因此单独评估，并没有把 decode 倍数套到首 token 或完整交互上。

**手机模型也是这套 PPU 优化吗？**

是相同模型家族的另一条部署路线。手机用公开 MNN HQQ 4-bit 模型和 CPU，赛事用固定 BF16 权重和 PPU，两个后端、硬件和评价任务分开。

**手机演示是否由电脑替模型操作？**

受控三步视觉闭环中，电脑负责准备和事后取证，模型选择、门检查、点击和状态转移在手机上完成。另有明确断 ADB 的 Settings 证明支持预部署后的运行时独立性。固定录屏脚本属于另一种展示方式，不能算模型自主证据。

**脑电已经控制手机了吗？**

尚未。公开脑电分类和手机动作分别有实测依据，连接部分仍待验证。下一步先做标注清楚的离线回放与候选确认，再验证真人采集和实时闭环。

**63.4%比随机只高一点，为什么继续探索？**

它显示有限识别能力与个体差异，无法支持连续自动执行，但可以支撑确认式原型的研究。我们并未继续扩大宣传，而是检查个人校准、静息拒识和覆盖代价，并保留没有提升的结果。

**EEG 的左右标签如何变成电话等复杂任务？**

由明确界面和候选任务规定语义，左右仅用于有限选择；确认后才形成结构化任务。不能让大模型从一个左右标签猜任意自然语言意图。电话、发送和支付等动作还需要具体授权，不能由二分类直接触发。

**VLA 已经通过训练自动改进了吗？**

目前材料提供了数据治理、转换、训练与回归路线，不能证明已经获得候选模型的稳定训练收益。只有合格数据、真实训练/checkpoint/reload 和匹配评测完成，才可以报告能力改进。
