# 中文公开集全量精度验证

## 目标

在本地真实 Transformers 后端上完整运行 MMBench Dev CN，验证 O1
`torch.inference_mode()` 路径在 4029 条公开样本上的精度、答案解析和结果完整性。

本实验用于扩大 Accuracy 证据范围。全量运行只有一次，TTFT 和 Throughput 仅用于
运行健康检查；正式本地性能结论仍采用固定 20 条、三次复测的中位数。

## 配置

- 数据集：MMBench Dev CN
- 样本数：4029
- 模型：Qwen3.5-2B
- 后端：`transformers`
- 精度：BF16
- Profile：O1 `torch.inference_mode()`
- 批大小：1
- warmup：2
- 分块大小：200，最后一块 29 条
- 分块数：21
- TTFT 口径：首个生成 token 入队时刻

## 结果

- Accuracy：83.9414%（3382/4029）
- 错误样本：647
- 平均 TTFT：340.984 ms
- 平均吞吐：18.739 tokens/s
- 公开接口校验：4029/4029 通过
- 无效答案：0

### 一级类别

| 类别 | 样本数 | 正确数 | Accuracy |
|---|---:|---:|---:|
| Attribute Reasoning | 663 | 567 | 85.52% |
| Coarse Perception | 1024 | 911 | 88.96% |
| Fine-grained Perception（跨实例） | 494 | 379 | 76.72% |
| Fine-grained Perception（实例级） | 1060 | 929 | 87.64% |
| Logic Reasoning | 373 | 265 | 71.05% |
| Relation Reasoning | 415 | 331 | 79.76% |

## 完整性审计

合并结果通过以下独立检查：

- 21/21 分块存在并通过来源与分块 SHA-256 校验；
- 合并后恰有 4029 个唯一题目 ID；
- 合并结果 ID 集合与原始 TSV 完全一致；
- 没有缺失 ID、重复 ID 或额外 ID；
- 每个分块均使用 `transformers`、O1 和首 token TTFT 口径；
- 由逐样本结果重新计算得到 3382 个正确答案，与汇总字段一致；
- `chunk_merge.complete = true`。

## 结论

中文完整公开集 Accuracy 为 83.94%，与中文比例分层 200 条的 84.5% 接近，没有
出现扩展样本规模后的异常精度坍塌。当前较弱的一级类别是 Logic Reasoning 和
Fine-grained Perception（跨实例）。后续优化应优先做分层误差分析，同时保持统一的
答案解析和公开接口校验，避免为了少量公开题目定向调参。

本结果来自本地 RTX 4050，不代表阿里云 PPU 的性能或比赛私有集成绩。
