# 英文公开集全量精度验证

## 目标

在本地真实 Transformers 后端上完整运行 MMBench Dev EN，验证 O1
`torch.inference_mode()` 路径在 4029 条公开样本上的英文精度、答案解析和结果完整性。

本实验用于扩大 Accuracy 证据范围。全量运行只有一次，TTFT 和 Throughput 仅用于
运行健康检查；正式本地性能结论仍采用固定 20 条、三次复测的中位数。

## 配置

- 数据集：MMBench Dev EN
- 样本数：4029
- 模型：Qwen3.5-2B
- 后端：`transformers`
- 精度：BF16
- Profile：O1 `torch.inference_mode()`
- 批大小：1
- warmup：2
- 分块大小：200，最后一块 29 条
- 分块数：21
- TTFT 口径：首个生成 token 入队时刻

## 原始全量结果

- Accuracy：79.7220%（3212/4029）
- 平均 TTFT：339.300 ms
- 平均吞吐：18.902 tokens/s
- 公开接口校验：4028/4029 通过
- 无效答案：1

唯一无效答案是题号 `1001659`。模型生成到 256-token 上限时已在选项分析中把 C
标记为加粗的 “matches exactly”，但在输出最终 `Answer: C` 前被截断，原解析器
因此返回空。该样本在原始结果中按错误计分，原始 Accuracy 没有虚高。

## 通用解析鲁棒性修复

`evaluation_wrapper.py` 新增严格的结论规范化：

- 仅当输出中恰有一个选项带加粗的明确正向结论时触发；
- 已有标准 `Answer:` 的输出不修改；
- 多个正向结论、未加粗推测或普通选项分析不修改；
- 不读取题号或参考答案；
- 只在返回文本末尾追加规范的 `Answer: X`，不改变模型 token 数。

单元测试覆盖正常、歧义、未加粗和已有标准答案四类边界。随后完整重跑异常所在的
200 条分块，与原分块逐样本比较：

- 200 个题号完全一致；
- 200 个 token 数完全一致；
- 199 个已有解析答案完全一致；
- 仅 `1001659` 从空值恢复为 C；
- 分块 Accuracy 从 80.0% 提升到 80.5%；
- 分块公开接口校验从失败变为通过。

## 修复后严格合并结果

- Accuracy：79.7468%（3213/4029）
- 错误样本：816
- 平均 TTFT：339.254 ms
- 平均吞吐：18.915 tokens/s
- 公开接口校验：4029/4029 通过
- 无效答案：0

### 一级类别

| 类别 | 样本数 | 正确数 | Accuracy |
|---|---:|---:|---:|
| Attribute Reasoning | 645 | 502 | 77.83% |
| Coarse Perception | 1029 | 901 | 87.56% |
| Fine-grained Perception（跨实例） | 495 | 370 | 74.75% |
| Fine-grained Perception（实例级） | 1053 | 900 | 85.47% |
| Logic Reasoning | 386 | 217 | 56.22% |
| Relation Reasoning | 421 | 323 | 76.72% |

## 完整性审计

修复后合并结果通过以下独立检查：

- 21/21 分块存在并通过来源与分块 SHA-256 校验；
- 合并后恰有 4029 个唯一题目 ID；
- 合并结果 ID 集合与原始 TSV 完全一致；
- 没有缺失 ID、重复 ID 或额外 ID；
- 每个分块均使用 `transformers`、O1 和首 token TTFT 口径；
- 由逐样本结果重新计算得到 3213 个正确答案，与汇总字段一致；
- 仅一个样本带 `choice_conclusion_normalized=true`；
- `chunk_merge.complete = true`。

## 结论

英文完整公开集 Accuracy 为 79.75%，相对英文比例分层 200 条的 82.5% 有一定下降，
但没有出现精度坍塌。当前最弱的一级类别是 Logic Reasoning，其次是跨实例
Fine-grained Perception。解析修复来自完整集暴露出的通用格式边界，并通过整个
200 条分块的逐样本不变性验证，不是按题号或答案定向修补。

本结果来自本地 RTX 4050，不代表阿里云 PPU 的性能或比赛私有集成绩。
