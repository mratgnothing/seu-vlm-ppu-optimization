# 规则与边界

## 主要指标

- Accuracy：正确样本数 / 总样本数。
- TTFT 提升率：`1 - T_opt / T_ori`。
- Throughput 提升率：`T_opt / T_ori - 1`。
- 初赛总分口径：40% Accuracy、30% TTFT、30% Throughput。

整体评比中还包含系统级优化，因此报告必须保留算子、调度、内存和硬件适配证据。

## 允许研究

- 模型加载、dtype、初始化和设备映射。
- 推理后端、静态图、算子和 kernel 优化。
- KV Cache、prefill/decode、图像预处理和 tokenizer。
- 算子融合、调度、内存管理和 PPU 指令/工具链适配。

## 明确禁止

- 更换模型、使用未获认可的量化权重包或蒸馏模型。
- 修改正式数据、评分逻辑或反作弊逻辑。
- 跳过/筛选样本，或按 ID、题干、图片 hash 查表。
- 硬编码答案或调用外部模型、搜索和远程推理服务。
- 伪造 token 数、TTFT、总耗时或使用两套评测策略。
- 利用解析漏洞、异常输出或跨次持久缓存获利。

## 待主办方确认

赛题鼓励量化和剪枝，但资料包限制未经认可的权重变换。在得到书面确认前，优先研究运行时低精度、KV Cache 量化和主办方认可格式，不将离线剪枝或量化权重包作为正式提交路线。
