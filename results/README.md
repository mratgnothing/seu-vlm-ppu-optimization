## 当前可公开聚合结果

环境：RTX 4050 Laptop GPU 6GB、BF16、batch size 1、公开集固定前 20 条、2 条预热。

| 数据/版本 | Accuracy | Avg TTFT | Throughput | 校验 |
|---|---:|---:|---:|---|
| 中文 O0 基线 | 85% | 327.451 ms | 21.813 tokens/s | 通过 |
| 英文 O0 基线 | 80% | 409.660 ms | 28.685 tokens/s | 通过 |
| 中文 O1 三次中位数 | 85% | 290.946 ms | 23.150 tokens/s | 三次均通过 |
| 英文 O1 交叉验证 | 80% | 351.892 ms | 33.462 tokens/s | 通过 |

O1 相对中文 O0 的保守中位提升为：TTFT 11.15%，吞吐 6.13%，逐样本答案和 token 数均无变化。
英文单次交叉验证的 TTFT/吞吐提升为 14.10%/16.65%，逐样本答案和 token 数同样无变化。

这组结果用于工程管线验证，不代表完整公开集或主办方私有评测成绩。逐样本原始结果保留在本地忽略目录，不提交到仓库。
