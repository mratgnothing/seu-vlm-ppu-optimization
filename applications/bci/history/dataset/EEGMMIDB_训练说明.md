# PhysioNet EEGMMIDB：下载与初步训练说明

## 来源与目录

- 官方版本：EEG Motor Movement/Imagery Dataset 1.0.0。
- 官方页面：https://physionet.org/content/eegmmidb/1.0.0/
- DOI：https://doi.org/10.13026/C28G6P
- 许可：Open Data Commons Attribution License v1.0，以官方页面为准；使用和发表时引用数据集及原始 BCI2000 论文。
- 本地目录：`E:\BCI\datasets\physionet-eegmmidb-1.0.0`。
- `raw/`：官方原始记录，保留 S001—S109 目录以及全部 14 个 runs。
- `metadata/SHA256SUMS.official.txt`：官方文件 SHA-256 校验表。
- `metadata/download_verification.json`：下载、校验、EDF 结构检查与文件计数结果。
- `metadata/all_edf_inventory.csv`：全部 EDF 记录索引。
- `metadata/left_right_imagery_runs_04_08_12.csv`：初步左右手运动想象实验索引，仅引用原始文件，不复制数据。

完整数据包含实际运动、运动想象和基线休息记录。初步训练只选择 **runs 4、8、12**；这些 runs 中 T0=休息、T1=左手运动想象、T2=右手运动想象。首个二分类模型只使用 T1/T2。其他 runs 的 T1/T2 含义可能不同，不能混用。

### 本轮下载验收

2026-09-30 已完整下载官方清单中的 3,058 个文件，逐文件 SHA-256 全部一致。包含 109 名受试者、1,526 个 EDF 和 1,526 个独立事件文件，原始数据共 3,614,708,069 bytes（约 3.37 GiB）。左右手运动想象索引包含 327 个 EDF，共约 795 MiB。

逐文件 EDF 头部和文件长度检查全部通过。发现 **S088、S092、S100 的 runs 3—14 为 128 Hz**，其余记录为 160 Hz；初步训练集内受影响的是这三人的 runs 4、8、12，共 9 个记录。训练需依据实际头信息选择明确的重采样/纳入策略，并记录质量检查与处理理由；不要在读取阶段硬编码 160 Hz。校验通过不代表生理信号无伪迹或所有记录都适合训练。

## 初步模型

### 基线一：CSP + LDA

- 使用 MNE-Python 读取 EDF 和事件，scikit-learn Pipeline 串联 CSP 与 LDA。
- 第一轮只读取 5—10 名受试者，确认波形、单位、事件、通道名称与采样率。
- 候选预处理：8—30 Hz 带通，使用运动提示后 1—4 秒的 EEG 窗口；这些属于初始实验配置，后续按训练侧验证调整。
- CSP 初始使用 4—8 个分量；CSP 和标准化仅在训练折内拟合。
- 每人先做按 run 留出评估，再扩展全部受试者与跨人测试。
- MNE 官方示例：https://mne.tools/stable/auto_examples/decoding/decoding_csp_eeg.html

### 基线二：EEGNet

- 使用 PyTorch/Braindecode 的紧凑 EEG 卷积网络，输入是多通道时序数值，不把 EEG 图片作为 VLM 输入。
- 第一轮可采用 F1=8、D=2、F2=16 的常见紧凑配置；记录软件版本和具体实现的默认参数。
- 输入按 `[batch, channels, samples]` 组织；例如 64 通道、160 Hz、4 秒约为 640 个时间点。实际 epoch 长度以代码采样边界为准。
- 初始 batch size=32，显存不足时降为 16；不要求使用混合精度。
- Adam/AdamW，初始学习率 1e-3，最多约 100 epochs，按独立验证集早停；这些均是起始配置而非已验证最优值。
- EEGNet 论文：https://arxiv.org/abs/1611.08024

## 算力规划

以下为实验规模的工程预算，不是本项目已测量结果。

| 模型 | 建议算力 | RAM 预算 | 备注 |
|---|---|---|---|
| CSP-LDA，小规模逐受试者 | 常规多核 CPU；无需 GPU | 8 GB 可起步，16 GB 更方便 | 逐人读取，避免全量原始记录驻留内存 |
| EEGNet，小规模训练 | CPU 可跑；4 GB 显存 GPU 可起步 | 16 GB 建议 | batch 16—32、短 epoch，实际占用随实现变化 |
| EEGNet，全受试者与跨人评估 | 本机 RTX 4050 Laptop 6 GB 可以开展 | 16 GB 起步，32 GB 更方便 | 按任务读取/缓存；多折、多种随机种子会增加累计时间 |

本机当轮检测到 i7-13650HX、约 32 GB 内存（系统可见约 31.6 GiB）和 RTX 4050 Laptop GPU 6141 MiB。无需购买额外算力来开展上述两种基线。训练时尽量避免同时运行占显存的 Qwen/VLM。具体耗时应先做小规模真实训练后报告。

## 评估与边界

1. 同人跨 run、跨人留出分别报告；不把两个结果混成一个准确率。
2. 同一试次的重叠窗口不得分散到训练与测试集合。
3. 先划分再拟合 CSP、缩放器、特征选择、校准器；测试集不调参、不选阈值。
4. 报告各受试者样本量、混淆矩阵、平衡准确率、区间和失败样例，并加入标签打乱对照。
5. 官方文件校验通过只说明下载完整；仍需检查异常记录、伪迹、类别缺失和采样差异，并记录纳入/排除原因。
6. 休息/无操作检测是独立实验，二分类最大概率不能直接视为可靠执行授权。
7. “确认”“取消”是交互协议映射，不是这个数据集里的原生脑电语义标签。
8. 本数据集适合跨 run、跨人研究；跨天泛化后续使用有明确不同日期 sessions 的 BCI Competition IV-2a。
9. 在线回放使用因果滤波，仅访问当前及过去数据；离线双向滤波结果不能直接代表流式系统。

本次仅下载、校验并提供训练规划，没有执行模型训练，也没有实测分类准确率或训练时间。
