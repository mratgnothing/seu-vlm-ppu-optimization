# 第四轮：脑机接口原型改进验证

本任务为用户请求的有限改进实验，目标是判断哪些改进值得进入原型。所有数据与旧任务保持不变，使用本地 RTX4050 Laptop；无云算力、无手机控制。

## 结果

- 左右识别：分类头个人校准基线63.4%，复跑仍63.4%；对齐协方差线性模型58.0%，全网络微调61.0%。本轮没有进一步提高左右识别。
- 休息检测：拆分休息/动作与左右分类，并加入个人run04休息标注校准。保守阈值下17/206个动作候选、14正确，6/204休息误触发；同run12旧门控1/206个动作候选，5/204休息误触发。较宽松运行点66/206输出、43正确、36/204误触发。
- 82.4%只表示保守阈值下17个已输出动作的方向正确率。加入6个休息误触发后，全部23个候选中14正确，60.9%。仍需人工确认。
- 条件标签置乱支持预测与标签有关联，但不是新的独立泛化证据，不能说明新方案优于旧方案或解码机制已确认。
